# C, C++ and other languages

## C and C++
C is procedural with manual memory management; C++ adds classes, templates and the standard library. Compile with warnings enabled and fix them. Common problems: uninitialised variables, off-by-one array access, memory leaks, dangling pointers, missing header guards, and linker errors from missing definitions. Learn to read compiler messages from the first error, since later errors are often consequences. Prefer std::string, std::vector and smart pointers in modern C++.

## PHP, Go, Ruby, R and C#
PHP powers many web back ends; use prepared statements and escape output. Go has simple syntax, goroutines and a strong standard library; go vet finds suspicious code and gofmt formats it. Ruby emphasises readable code; Rails is its web framework. R is designed for statistics and visualisation; data frames and the tidyverse are central. C# runs on .NET and shares many ideas with Java.

## Choosing a language for a project
Use the language the course or team expects. Python is strong for data and AI; Java and C# for large structured applications; JavaScript for web front ends; C and C++ for performance-critical or embedded work; SQL for data queries.
