# Web development and JavaScript

## JavaScript essentials
Variables are declared with let and const. Functions are first-class values; arrow functions are a compact syntax. Arrays have map, filter and reduce. Asynchronous work uses promises and async/await. The DOM represents a web page; events let code respond to the user. Use the browser developer console to inspect errors.

## Node and packages
Node.js runs JavaScript outside the browser. npm installs packages listed in package.json. node_modules should never be committed. Express is a minimal web framework for building HTTP APIs: routes map URLs and methods to handlers.

## HTML, CSS and forms
HTML gives structure, CSS gives presentation, JavaScript gives behaviour. Use semantic elements, label form inputs, and validate input both in the browser and on the server. Responsive layouts use flexbox, grid and media queries.

## Python web frameworks
Flask is a lightweight framework with routes and templates. FastAPI builds typed APIs with automatic documentation. Streamlit turns scripts into simple data apps. Keep business logic out of route handlers so it can be tested.
